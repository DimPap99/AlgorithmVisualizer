Instructions:

Choose a Start Point and an End point by clicking on the respective button and then on a cell.
Add walls (optional) by holding your mouse button down while dragging it across the grid. Dragging from a wall erases walls.
Add weights (optional) the same way with the custom weight, or generate them from a distribution. Moving into a cell costs its weight.
Only Bellman-Ford allows negative weights. If going around some cells lowers the cost each time (a negative cycle), there is no cheapest path and it highlights the cycle.
Choose the Find Path button to watch the selected algorithm discover nodes until the End Point is found and the
path back to the Start Point is drawn! You can use the Clear button to clear the grid.
