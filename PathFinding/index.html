Instructions
  • Select Start or End, then click a cell. Use arrow keys to move between cells and Enter to select one.
  • Select Walls or Weights, then click or drag to paint cells. Clicking a painted cell erases it.
  • Each move costs the weight of the destination cell. BFS and DFS ignore weights.
  • Only Bellman-Ford accepts negative weights. A negative cycle means there is no cheapest path.
  • Find path runs the selected algorithm. Stop cancels computation or animation. Clear grid resets everything.
